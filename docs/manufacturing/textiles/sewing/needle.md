# Needles

Sewing machine needles are defined with 2 numbers ( 90/14 common )

- 90 = 0.9 mm thickness (EU metrix size)
- 14 =  (U.S. size)
    - each increment is a 0.05 mm

There is no standard sizing for needle sharpness/curvature. But needles that are ment for thicker fabrics often are sharper!
