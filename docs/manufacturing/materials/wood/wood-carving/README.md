# Wood Carving

Wood Carving is hard! It is kinda like knitting where you have to sit and carve for awhile to make someting you like. But can be meditative and can be something to do while watching TV, talking, taking the bus/train.

Since basswood (still hard to carve) is the default carving wood. You can buy it from art stores! It actually turned out to be cheaper to buy from `Blick` than the wood store below!!! The pieces were already cut and smooth the handheld size for carving a little figure.
