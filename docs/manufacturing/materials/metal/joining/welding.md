# Welding

[https://en.wikipedia.org/wiki/Welding](https://en.wikipedia.org/wiki/Welding)

It is a fabrication process of joining materials (metals or thermoplasics) via melting parts via heat and allowing them to cool together, called fusion.

Alternatively, solvent welding (of thermoplasics) can use chemicals and solid-state welding via pressure, cold welding, diffusion bonding instead of heat.
