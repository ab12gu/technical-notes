# Routine Tests

Complete Blood Count (CBC)

- Detects:
    - Anemia
    - Infections
    - Blood Disorders
- Red BC, White BC, Hemoglobin, Hemocrit, Platelets

Comprehensive Metabolic Panel (CMP)

- Detects
    - Liver problems
    - Kidney disease
    - Blood sugar issues
- Glucose, Sodium/Potassium, Calcium, Liver Enzymes, Kidney markers (BUN, Creatine)
