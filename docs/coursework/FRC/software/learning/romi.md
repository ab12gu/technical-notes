# Romi

The hardware developers [Pololu](https://www.pololu.com/product/4022) don't develop instructions on how program a ROMI based on FRC, and actually don't really provide and software guidelines!

The [software guidelines](https://docs.wpilib.org/en/stable/docs/romi-robot/programming-romi.html) on wpilib are actually quite sparse. It tells you how to run wpisimulate and connect to ROMI, and a way to control it via LabView onsecond page. 

ChainLynx maintains a better set of instructions more closely related to how develop in WpiLib:

- [https://git.emeraldcityrobotics.org/chainlynx/Romi-Projects/src/branch/2027](https://git.emeraldcityrobotics.org/chainlynx/Romi-Projects/src/branch/2027)

There is also a backup github version, but only used when the Forgejo server isn't available/accessable (hosted by John at Roosevelt).

See [Hardware/Romi](../../../hardware/romi/) for more details on the Romi's.
