# Software

WPILib is the standard software library and toolsuite provided for teams to write, test, and debug code for their FIRST® Robotics Competition and FIRST® Tech Challenge robots.

The libraries have links to be able to be called from Java, C++, and Python.

WPI - Worchester Polytechnic Institute. WPILib was originally created by Brad Miller and some Worchestor Polytechnic Institute students back in the early 2000s (I think 2008?). [source](https://www.chiefdelphi.com/t/psa-wpilib-ask/401876)

- [github.com/wpilibsuite](https://github.com/wpilibsuite)
- [https://wpilib.org/](https://wpilib.org/)

## Getting Started

You'll need to install [WPILib](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html) and later follow the instructions to download other dependency software. Wpilib has libraries used for FRC, but is integrated into a custom VSCode.

Other Software Required

- shuffleboard - included in wpilib install
- advantagescope - included in wpilib install
- SmartDashboard - included in wpilib install
- Drivers station
- NI (need username/password, see separate file)

**NOTE:** WPILib needs to be reinstalled every year w/ new VSCode
