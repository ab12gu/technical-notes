# Fonts

I use Tinos, [https://fonts.google.com/specimen/Tinos](https://fonts.google.com/specimen/Tinos), font for my resume. It mimics the character spacing/sizing of [Times New Roman](https://en.wikipedia.org/wiki/Times_New_Roman), but isn't proprietary...

Two types of Fonts:

1. [Serif](https://en.wikipedia.org/wiki/Serif)
    - Contains extra strokes within characters
    - Harder to read on lower resolution displays
2. [Sans-Serif](https://en.wikipedia.org/wiki/Sans-serif) doesn't have "serifs" at the end of strokes.
    - "Sans" means without in French

## Usage

For `wikipedia`, they use serif for title (`Georgia` or `Times New Roman`) because font is larger, and render default OS san-serif (`Helvetica` for Mac and `Arial` for Windows).
