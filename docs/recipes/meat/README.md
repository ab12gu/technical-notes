# Meat

General rule:

- Just toss **salt/pepper** and let sit on counter for 10 minutes
- Then grill for 5-8 min each side
- If meat is fattier, you can use less/no salt 
    - salt helps tenderizes muscle fiber, retaining water, so it doesn't dry out

## Additional spices/marination

- olive oil
- lime juice
- garlic minced
- onion, finely diced
    - saute onion first
- chili powder**
- cumin**
- smoked paprika
- Oregano (or other herb)
- Coriander

Also

- tomato paste
