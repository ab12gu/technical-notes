# Tamarind

FRUIT! - that looks like soybeans/edamame pods

![](https://thumb.wikimedia.org/wikipedia/commons/thumb/2/2e/Tamarindus_indica_pods.JPG/500px-Tamarindus_indica_pods.JPG?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail){width=300px}

Flavor: sweet/tangy pulp

The seeds are quite large, but can be pressed into seed oil. Leaves are used on cuisines too. But the oils are used for the textile industry: sizing agent for cotten and used as varnishes.
