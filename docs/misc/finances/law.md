I wrote a script to extract the contact information of lawyers and then automated emailing all of them. 

- Email providers limit # of emails per day (Gmail 500)
- [https://github.com/ab12gu/scripts/tree/main/law-emails](https://github.com/ab12gu/scripts/tree/main/law-emails)

## WA Lawyers

Database of WA Lawyers: 

- Washington State Bar Association [https://www.wsba.org/](https://www.wsba.org/)
    - Use the `Legal Director`
    - Edit search Results to be able to specify `Area of Practice`
    - [mywsba.org/PersonifyEbusiness/LegalDirectory.aspx?](https://www.mywsba.org/PersonifyEbusiness/LegalDirectory.aspx?)
- Superlawyers [attorneys.superlawyers.com/personal-injury-plaintiff/washington/seattle/](https://attorneys.superlawyers.com/personal-injury-plaintiff/washington/seattle/)
    - Only provides phone number

## CA Lawyers
