# Website Encryption

[MkDocs Encryption Plugin](https://github.com/unverbuggt/mkdocs-encryptcontent-plugin)

- encrypt/decrypt markdown content with AES
    - encrypted with AES-256 in Python using PyCryptodome
    - decrypted in the browser with Crypto-JS or Webcrypto
