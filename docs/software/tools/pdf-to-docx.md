# pdf-to-docx

The reason this is useful atm is because recruiters request a `docx` version of my resume so they can add keywords for better matching. 


Options:

- Microsoft word (desktop,paid or online,free) upload file `pdf`
- Adobe Acrobat - Convert (Paid)
- Online Websites
    - [https://www.ilovepdf.com/](https://www.ilovepdf.com/)

## Tex to docx

Lots of sources say to use `pandoc`

The issue is that `pandoc` sucks and doesn't really render good docx files

But, [https://www.ilovepdf.com/](https://www.ilovepdf.com/) works amazingly well!
