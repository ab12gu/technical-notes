# App Development

## Mac Apps

It costs $100 a year to deploy an app on the Apple Store. There is no workaround unless you jailbreak your phone.

Alternatives

1. iPhone in development mode can receive an app signed for 7 days from Xcode
2. [Trollstore](https://github.com/opa334/TrollStore) - allows unsigned apps somehow without jailbreak... not up to date with latests os's
3. Jailbreak
4. Testflight - [https://testflight.apple.com/](https://testflight.apple.com/)
    - from apple to test development of apps
    - You need an Apple Developer Program account ($99/year)
        - But if you had a friend w/ it they can launch ur app?
