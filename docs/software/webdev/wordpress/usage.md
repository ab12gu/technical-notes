# Usage

## Connection

To separate domain, need to add these records to host domain server to reroute server to wordpress:

| Type | Name | Value |
| --- | --- | --- | 
| A | @ | 192.0.78.24 |
| A | @ | 192.0.78.25 |
| CNAME | wwww | lawregional.com |
