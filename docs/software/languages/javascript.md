# Javascript

Used in 99% of websites, created in 1995.


## Run on Computer

Install `node.js`

```bash
$ choco install nodejs # restart terminal after install to update paths
$ touch script.js
$ echo "console.log("hello world") >> ./script.js
$ node ./script.js
```
