# Microphones

I bought the [Behringer mic](https://www.amazon.com/dp/B0002KZAKS?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1) for Karayoke at gamenights for $20. The professional sennheisser that everyone uses is overkill...

The technology behind microphones is quite simple and has been the same for decades. Therefore, for good and for worse, the Sony microphone is most popular for concerts/recordings/etc. It retails just above $100, but is only really worth it if you like the brand/affilation people get when they see it. 

Most of the technology for these comes through noise filtering. There is audio hardware that can accomplish this though optimized lowpass filtering (high frequencies are generally noise), but much focus has been into software postprocessing, which could also be done on a chip on microphone or daw/computer.
