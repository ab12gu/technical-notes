# Maschine

[https://en.wikipedia.org/wiki/Maschine](https://en.wikipedia.org/wiki/Maschine)

DAW (digital audio workstation) developed by Native Instruments

## Fix

I bought a maschine mikro mk3, but it was missing large pad (ripped off). I bought some opaque silicon from aliexpress and cut it to fit eh slot. It works, but the controller software is proprietary, so don't think I can use it without the software.
